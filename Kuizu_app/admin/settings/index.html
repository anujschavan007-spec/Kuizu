KUIZU Admin Quick Reference

Architecture & Security Protocols

Anti-Cheating Guard: In-depth surveillance intercepts tab switching, copy/paste shortcuts, and browser window blur. All violations are logged in Cheating Logs.

Sound Engine: WebAudio orchestrates continuous background music playback in arenas and daily challenges with preset master volume attenuation.

Typography Engine: Custom font colors and type scales cascade globally through CSS variables across cards and dashboard widgets.

Database Synchronization: Supabase stores questions, contests, battles, and user scores with client-side optimistic caching.
